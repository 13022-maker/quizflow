# 適性練習儀表板「學習後分數」欄 設計文件

- 日期：2026-07-16
- 範圍：`src/app/[locale]/(auth)/dashboard/adaptive/[practiceId]/page.tsx`（僅顯示層）

## 需求
老師的班級儀表板知識點欄之後，新增「學習後分數」欄，一眼看出每位學生的整體掌握度。

## 決策
- **算法（使用者選定）**：全部知識點 `mastery` 平均 × 100，`Math.round` 取整。範例：92/87/25/25 → 57 分。
- 直接用頁面既有 `s.diagnosis` 現場計算，不加查詢、不動 API/DB/引擎。
- 顯示：≥80 綠、≥60 藍、其餘灰；數字加粗 + 「分」。
- 邊界：`diagnosis` 為空顯示「—」。

## 不做（YAGNI）
學習前後對比（診斷無初始快照）、排序、CSV 匯出。

## 驗證
`npm run lint`、`npm run check-types`；自動刷新頁面上肉眼核對黃小明 ≈ 57 分。
